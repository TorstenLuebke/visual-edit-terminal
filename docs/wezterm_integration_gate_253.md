# ShellDeck: wezterm-term integration gate (preliminary)

The preferred external-engine *candidate* is `wezterm-term` (Rust). No dependency
is added and no production engine is changed in patches 252–254.

Before fetching, building, packaging or distributing this candidate:

1. Choose and record a concrete upstream revision / crate version and API.
2. Generate Cargo.lock on an explicitly approved build machine; keep the
   build reproducible and review any build scripts and native dependencies.
3. Resolve complete transitive dependencies and license metadata, including
   bundled assets, fonts, code generated by build scripts and notices. The
   top-level MIT designation alone does not approve the dependency tree.
4. Check Linux, Windows 11 and macOS support in an actual CI build and verify
   permissible redistributions of each produced binary and required notices.
5. Exercise the shared binary cases, then cursor, SGR, Unicode, alternate screen,
   scrolling, selection, search, and resize/reflow on all target platforms.
6. Only after these gates pass consider a separate experimental adapter. Keep
   pyte available as rollback. Never switch the user-facing default silently.

`src/shelldeck_cargo_audit_253.py` inventories a local Cargo.toml and Cargo.lock
without invoking Cargo. This is **not** a license scanner or compliance approval:
Cargo.lock does not contain complete license facts. Incomplete audit blocks
integration, not the existing ShellDeck application.
